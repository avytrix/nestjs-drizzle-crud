The class signature:

```ts twoslash
// ---cut---
class SqlBaseCrudService<
  T,
  CreateDto = Partial<T>,
  UpdateDto = Partial<T>,
  FilterDto = Partial<T>,
> {}
```

The four generics correspond to:

| Generic | Default | Use |
| --- | --- | --- |
| `T` |  | The entity row type (typically `typeof table.$inferSelect`). |
| `CreateDto` | `Partial<T>` | The shape accepted by `create()` and `massCreate()`. |
| `UpdateDto` | `Partial<T>` | The shape accepted by `update()` and `massUpdate()`. |
| `FilterDto` | `Partial<T>` | The shape accepted by `findAll(filters)` and `count(filters)`. Use `CrudFilter` when filters come from [`parseQuery`](/docs/query-parsing). |

## Read

| Method | Returns | Notes |
| --- | --- | --- |
| `find(id, options?)` | `Promise<T \| null>` | By primary key. Skips soft-deleted rows. |
| `findOne(where, options?)` | `Promise<T \| null>` | `where` is a `Partial<T>`: exact, case-sensitive equality, `null` for `IS NULL`, or an operator object. `undefined` values are skipped; if nothing is left, or a key is not a column, it throws a 400 rather than returning an arbitrary row. |
| `findAll(filters?, pagination?, options?)` | `Promise<CrudPage<T>>`: `{ data, total, page, limit }` | `withCount: false` skips the count: `total` is `null` and `hasMore` is set ([Pagination](/docs/pagination-sorting#how-do-i-skip-the-count-query)). Supports `options.search`, `and` / `or` / `not` groups and multi-column or relation `sortBy`. An unknown filter key is a 400. Always ends `ORDER BY` with the primary key. See [Filtering](/docs/filtering) and [Pagination](/docs/pagination-sorting). |
| `findByCursor(filters?, pagination?, options?)` | `Promise<CursorPage<T>>` | Keyset pagination: `{ data, limit, nextCursor, total? }`. `total` only with `count: true`. See [Cursor pagination](/docs/cursor-pagination). |
| `exists(id, options?)` | `Promise<boolean>` | Cheaper than `find` when you only need a yes/no. |
| `count(filters?, options?)` | `Promise<number>` | Total rows matching the filter and `options.search`, ignoring pagination. |
| `countBy(column, filters?, options?)` | `Promise<CountByRow[]>` | `[{ value, count }]` per value of a column or a belongs-to `relation.column`, largest first. One `GROUP BY`. See [Aggregates](/docs/aggregates). |
| `parseId(raw)` | `Promise<unknown>` | Parses a route id by the primary key column: `ParseIntPipe` for an integer, `ParseUUIDPipe` for a uuid, `BigInt` for a bigint, the string otherwise. Bad input is a 400. |
| `idKind()` | `'int' \| 'bigint' \| 'uuid' \| 'string'` | What the primary key column holds. |
| `parseQuery(query, options?)` | `ParsedCrudQuery` | Turns an HTTP query object into `{ filters, pagination, options, ... }` for this entity. See [Parse query strings](/docs/query-parsing). |

Every read takes `withDeleted` / `onlyDeleted` to include or only return soft-deleted rows. See [Soft delete](/docs/soft-delete#how-do-i-list-soft-deleted-rows). Every read also takes `counts` for `_count` on each row ([Aggregates](/docs/aggregates)), and on an entity with a [`scope`](/docs/multi-tenancy) every read only sees the caller's rows.

### `find` signature

```ts twoslash
import { SqlBaseCrudService, type SqlOperationOptions } from 'nestjs-drizzle-crud';
type User = { id: number; name: string };
declare class S extends SqlBaseCrudService<User, User, Partial<User>, Partial<User>> {}
declare const s: S;
// ---cut---
const result = s.find(1);
const resultWithOptions = s.find(1, { relations: ['state'] });
```

### `findOne` signature

```ts twoslash
import { SqlBaseCrudService } from 'nestjs-drizzle-crud';
type User = { id: number; name: string; email: string };
declare class S extends SqlBaseCrudService<User, User, Partial<User>, Partial<User>> {}
declare const s: S;

```

### `findAll` signature

```ts
import { SqlBaseCrudService } from 'nestjs-drizzle-crud';
type User = { id: number; name: string; status: string };
declare class S extends SqlBaseCrudService<User, User, Partial<User>, Partial<User>> {}
declare const s: S;

const page = s.findAll(
  { status: 'active' },            // filters
  { page: 1, limit: 20 },          // pagination
  {
    relations: ['state'],
    search: { term: 'john', columns: ['name'] },
  },                               // options
);
```

### `count` with search

```ts
import { SqlBaseCrudService } from 'nestjs-drizzle-crud';
type User = { id: number; name: string; email: string; status: string };
declare class S extends SqlBaseCrudService<User, User, Partial<User>, Partial<User>> {}
declare const s: S;

const total = s.count(
  { status: 'active' },
  { search: { term: 'john', columns: ['name', 'email'] } },
);
```

## Write

| Method | Returns | Notes |
| --- | --- | --- |
| `create(data, options?)` | `Promise<T>` | Runs `validateCreate` → `mapCreateDtoToEntity` → `beforeCreate` → insert → `afterCreate`. |
| `update(id, data, options?)` | `Promise<T>` | Throws `EntityNotFoundException` if missing, and `ValidationFailedException` (400) when `data` has no column to set. |
| `delete(id, options?)` | `Promise<boolean>` | Hard delete. |
| `softDelete(id, options?)` | `Promise<boolean>` | Sets `deleted_at` to `now()`. Requires soft delete enabled. |
| `restore(id, options?)` | `Promise<T>` | Clears `deleted_at`. Throws `EntityNotFoundException` if missing. |
| `forceDelete(id, options?)` | `Promise<boolean>` | Hard delete, soft-deleted or not. |
| `upsert(data, upsert?, options?)` | `Promise<T>` | `ON CONFLICT DO UPDATE` (Postgres) or `ON DUPLICATE KEY UPDATE` (MySQL). `upsert` is `{ conflictTarget?, update? }`. See [Upsert](/docs/upsert). |
| `attach(id, relation, relatedIds, options?)` | `Promise<T>` | Links many-to-many rows through the join table; returns the row with the relation loaded. See [Relations on writes](/docs/relations-on-writes). |
| `detach(id, relation, relatedIds?, options?)` | `Promise<T>` | Unlinks the ids, or every link when `relatedIds` is left out. |
| `sync(id, relation, relatedIds, options?)` | `Promise<T>` | Makes the links exactly `relatedIds`. |

Writes take `options.relations` and `options.counts` and return the rows with them loaded. With [`versionColumn`](/docs/optimistic-locking), `update`, `softDelete`, `restore` and `delete` take `expectedVersion` (or the version in the body) and answer a stale one with a 409. With [global hooks](/docs/events) on, every write raises a before and an after event.

`create`, `update` and `upsert` apply [`writableColumns`](/docs/allowlists#which-columns-can-a-body-write-by-default). Without it, `update` ignores the primary key and `createdAt`, and both ignore the soft delete column.

## Bulk (single transaction, rolls back on any failure)

| Method | Returns |
| --- | --- |
| `massCreate(data[], options?)` | `Promise<T[]>` |
| `massUpdate(ids[], data, options?)` | `Promise<T[]>` |
| `massSoftDelete(ids[], options?)` | `Promise<boolean>` |
| `massRestore(ids[], options?)` | `Promise<T[]>` |
| `massDelete(ids[], options?)` | `Promise<boolean>` |
| `massForceDelete(ids[], options?)` | `Promise<boolean>` |
| `massUpsert(data[], upsert?, options?)` | `Promise<T[]>` |

Each method is one statement for the whole set (plus one `SELECT` that checks the ids exist), and `bulkMode: 'perItem'` runs the single-row method per item instead. When the statement fails, the items that fail are named. Throws `BulkOperationException` on failure; its 400 body is `{ statusCode, error, message, errors: [{ index | id, status, message }] }`. See [Bulk operations](/docs/bulk-operations).

## Search

| Method | Returns | Notes |
| --- | --- | --- |
| `fullTextSearch(term, columns, pagination?, options?)` | `Promise<{ data: T[]; total: number; page: number; limit: number }>` | PostgreSQL only. Same envelope as `findAll`. `to_tsvector(...) @@ plainto_tsquery(...)` with `ts_rank` ordering, then the primary key. Always applies page and limit. An unknown column is a 400. Excludes soft-deleted rows when soft-delete is enabled. |

## Transaction helper

```ts twoslash
import { SqlBaseCrudService } from 'nestjs-drizzle-crud';
type User = { id: number; name: string };
class S extends SqlBaseCrudService<User, Omit<User, 'id'>, Partial<User>, Partial<User>> {
  // Called from inside a service method.
  doIt() {
    return this.executeSqlTransaction(async (tx) => {
      return this.create({ name: 'Ada' }, { transaction: tx });
    });
  }
}
declare const s: S;
// ---cut---
const result = s.doIt();
```

`executeSqlTransaction(callback)` opens a transaction, runs the callback with the transaction handle, commits on success, rolls back on any throw.

## `SqlOperationOptions`

```ts twoslash
// ---cut---
interface SqlOperationOptions {
  /** Run within an existing transaction. */
  transaction?: any;
  /** Return only these columns. A dotted entry narrows a relation, at any depth. */
  select?: string[];
  /** Eager-load these configured relations. A dotted path nests: 'state.country'. */
  relations?: string[];
  /** Search configured table columns in findAll() and count(). */
  search?: {
    term: string;
    columns: string[];
    mode?: 'ilike' | 'fullText';
  };
  /** Skip before/after hooks for this call. */
  hooks?: {
    skipBefore?: boolean;
    skipAfter?: boolean;
  };
  /** Row-level lock. PostgreSQL only. See [Row-level locks](/docs/row-locks). */
  lock?: 'update' | 'share' | 'none';
  /** Use FOR NO KEY UPDATE. PostgreSQL only. See [Row-level locks](/docs/row-locks). */
  forNoKeyUpdate?: boolean;
  /** Also return soft-deleted rows. */
  withDeleted?: boolean;
  /** Return only soft-deleted rows (the trash). */
  onlyDeleted?: boolean;
  /** Skip the entity's allowlists for a trusted, server-side call. */
  skipAllowlists?: boolean;
  /** Mass writes: one statement ('set', default) or one call per item ('perItem'). */
  bulkMode?: 'set' | 'perItem';
  /** Relation counts under `_count`: ['posts'] or { posts: { status: 'draft' } }. */
  counts?: string[] | Record<string, true | object>;
  /** The context a function `scope` reads. Defaults to CrudContext.current(). */
  context?: Record<string, unknown>;
  /** Run this trusted call without the entity's scope. */
  skipScope?: boolean;
  /** Do not raise module-level events for this call. */
  skipEvents?: boolean;
  /** Optimistic locking: the version the caller last read. */
  expectedVersion?: number;
  /** Optimistic locking for mass writes, keyed by id as a string. */
  expectedVersions?: Record<string, number>;
}
```

`relations` eager-loads relations declared in the entity's config: a top-level belongs-to joins the main query, while has-many, many-to-many and every nested level add one batched query each for the whole result set. Never one query per row. See [Relations](/docs/relations).

`select` narrows the projection, and a dotted entry narrows an eager-loaded relation at any depth (`['id', 'name', 'region.code', 'states.cities.name']`). See [Column selection](/docs/column-selection).
