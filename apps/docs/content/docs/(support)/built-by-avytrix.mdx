## What NestJS and Drizzle experience does this library show?

The library is public, so you can judge the work directly instead of taking a claim on trust.
Everything in this table is in the [repository](https://github.com/avytrix/nestjs-drizzle-crud).

| What | Where to check it |
| --- | --- |
| A NestJS module with `forRoot`, `forRootAsync` and `forFeature` | [Configuration with forRoot](/docs/for-root) |
| One service class over Drizzle for PostgreSQL, MySQL and SQLite | [Defining services](/docs/defining-services) |
| Relations without N+1 queries, at any depth | [Relations](/docs/relations) |
| Tenant isolation on every read and write | [Multi-tenancy](/docs/multi-tenancy) |
| A generated REST controller with OpenAPI | [Controller factory](/docs/controller-factory) |
| An MCP server shipped inside the npm package | [AI agents and MCP](/docs/ai-agents) |
| End-to-end tests over real HTTP against Postgres (PGlite) | [The e2e suite on GitHub](https://github.com/avytrix/nestjs-drizzle-crud/tree/main/apps/api/e2e) |
