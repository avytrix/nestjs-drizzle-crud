Commercial support for nestjs-drizzle-crud comes from Avytrix Technologies, the company that
builds and maintains the library. You can hire the team to integrate the package into a NestJS
API, migrate from @nestjsx/crud or TypeORM to Drizzle, build an MCP server over your data, add
features your project needs, or review how your services use the library. Every engagement starts
with a free consultation.

<Callout title="Community help stays free">
  You do not need a contract to get an answer. Bugs and questions go to the
  [GitHub issue tracker](https://github.com/avytrix/nestjs-drizzle-crud/issues), as described in
  [Getting help](/docs/getting-help). This page is for work on your own codebase, on your
  schedule.
</Callout>

## What can the team do for a project that uses nestjs-drizzle-crud?

| Work | What it means in practice |
| --- | --- |
| **Integration** | Wire `DrizzleCrudModule` into an existing NestJS app: connection, services, controllers, OpenAPI, tests. |
| **Migration from @nestjsx/crud** | Move `@Crud` controllers and TypeORM services to Drizzle tables and `SqlBaseCrudService`, keeping your routes. See [Migrating from @nestjsx/crud](/docs/migrate-from-nestjsx-crud) for the steps. |
| **Migration from TypeORM or Prisma** | Move the data layer to Drizzle and the CRUD code to this package. See [Drizzle vs TypeORM vs Prisma](/docs/drizzle-vs-typeorm-prisma) for the trade-offs. |
| **Multi-tenant APIs** | Tenant scoping on every read and write, built on [multi-tenancy](/docs/multi-tenancy) and [allowlists](/docs/allowlists). |
| **MCP servers and AI features** | Model Context Protocol servers that let Claude, ChatGPT or Cursor work with your APIs and database. See the [MCP server development service](https://avytrix.dev/services/mcp-server-development?utm_source=nestjs-drizzle-crud&utm_medium=docs&utm_campaign=commercial-support). |
| **Custom features** | Behaviour your project needs, built in your codebase, or proposed upstream through a normal pull request when it belongs in the library. |
| **Reviews** | A review of how your services, filters, relations and transactions use the package, with the fixes written down. |
| **Ongoing support** | Monitoring, bug fixes, security updates and new features on business-hours, extended or 24/7 plans, as listed on the [ongoing support service](https://avytrix.dev/services/ongoing-support?utm_source=nestjs-drizzle-crud&utm_medium=docs&utm_campaign=commercial-support). |
