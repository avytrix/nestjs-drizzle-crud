## Why sponsor?

A CRUD layer sounds simple until you own it in production. This is what the package absorbs for you:

- **Dialect differences.** PostgreSQL `RETURNING` against MySQL `insertId`, and the different shapes drivers use to report affected rows.
- **Error mapping.** Constraint violations and data errors become 404, 409 and 400 responses instead of a 500.
- **Query correctness.** Pagination that keeps `total` right under filters and search, collection filters that never inflate the count, and soft delete that no read path forgets.
- **Docs and examples.** The guides on this site are written against a running example app, and the e2e suite runs real SQL over HTTP.

That maintenance is ongoing work, given away for free. Sponsorship is what keeps it sustainable.
